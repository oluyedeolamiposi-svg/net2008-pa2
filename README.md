#net2008-pa2 
A Python tool that audits network device inventories against a YAML policy and generates an audit.json report./n
## Requirements
. Python 3
. PyYAML 
## Usage
Run the following command:
`python pa2.py PA2_sample.xml PA2_policy.yaml`
The program prints an inventory summary and generates audit.json in the current directory.
